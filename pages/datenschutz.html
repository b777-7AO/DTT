Hosting

Diese Website wird als statische Website über GitHub Pages gehostet, einem Dienst der GitHub Inc. Beim Aufruf der Seite verarbeitet GitHub automatisch Server-Logdaten, zum Beispiel IP-Adresse, Datum und Uhrzeit des Zugriffs sowie die aufgerufene Seite. Details entnehmen Sie der Datenschutzerklärung von GitHub: docs.github.com/site-policy/privacy-policies/github-general-privacy-statement.

Wir setzen keine Cookies und keine Tracking- oder Analyse-Tools ein. Schriftarten und Skripte werden selbst gehostet und nicht von externen Servern nachgeladen.

Kontaktaufnahme

Wenn Sie uns per Telefon oder E-Mail kontaktieren, verarbeiten wir die von Ihnen mitgeteilten Daten, zum Beispiel Name, Kontaktdaten und Inhalt der Nachricht, zur Bearbeitung Ihrer Anfrage.

Das Kontaktformular dieser Website versendet Ihre Eingaben direkt über Ihr eigenes E-Mail-Programm. Es gibt keinen serverseitigen Formularversand und keine Speicherung Ihrer Eingaben auf unserer Website.

3D-Konfigurator

Der 3D-Konfigurator verarbeitet von Ihnen ausgewählte oder hochgeladene Fotos ausschließlich lokal in Ihrem Browser. Es findet kein Upload dieser Bilder auf einen Server statt.

Wenn Sie eine Konfiguration per Link teilen oder daraus eine Anfrage stellen, enthält dieser Link ausschließlich die von Ihnen gewählten Optionen, zum Beispiel Torart, Maße und Farbe, keine Bilddaten.
